# Interview Question Creator

A Generative AI project that generates interview questions and answers from uploaded PDFs using:

- LangChain
- FAISS
- Open Source LLMs
- FastAPI
- RAG Architecture

## Features

- PDF Upload
- Semantic Search
- Interview Question Generation
- Answer Generation
- FastAPI UI

## Tech Stack

- Python
- FastAPI
- LangChain
- FAISS
- HuggingFace
- Sentence Transformers
